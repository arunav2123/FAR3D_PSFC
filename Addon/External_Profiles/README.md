# This script is designed for compiling external profiles for FAR3d. <br>
 This script should work for any .CDF file, but there are changes that might be needed depending on the variables in your CDF files. <br>
 These changes should be made in lines 19-27. Additionally, device specifics should be changed in lines 10, and 70-85. <br>
 Finally, this script does not include collumns for alphas, but including these or any other profiles follows the same design. <br>
